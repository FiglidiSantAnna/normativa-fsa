# Normativa FSA

I libri normativi dell'Istituto Figli di Sant'Anna in un'unica app: ricerca in tutti i testi, rinvii che si aprono, tavole «Chi decide?».

Si apre e si installa da: https://figlidisantanna.github.io/normativa-fsa/

Le Costituzioni sono nel testo approvato l'8 dicembre 2025. Gli altri libri sono nel testo rivisto e restano da rivedere dopo il Capitolo.
